ii Settings Rework Unofficial mod for end-4's dots-hyprland · Quickshell "ii"

Every option in the settings app. Findable.

The stock illogical-impulse settings app leaves 114 of its 284 options to be edited by hand in config.json. This rework gives each of them a control, adds search and section navigation, and tidies the layout without changing how the app feels.

What changes

All 284 options have a control

Default apps, night light schedule, bar resources, tray filters, scrolling, pomodoro timings, AI models and the rest. Lists are edited as text, and the AI model list as JSON that only saves while valid.

Search across every page

370 labels are indexed. Results show where each option lives and take you to the exact row.

Tabs ordered by use

Quick, Bar, Interface, Background, General, Services, Advanced, then Misc and About. Options that nothing in the shell reads are moved to Misc.

Calmer rows

Sections are grouped on cards, per-row icons are gone, units moved out of the labels, and short text values no longer take a full-width box.

Displays page

Drag your monitors into place and set resolution, refresh rate, scale and rotation, with the result written to Hyprland's monitors.lua. New settings are undone after 15 seconds unless you keep them, so a mode your screen cannot show never leaves you stuck.

Update check and update button

About reports how many commits your dotfiles are behind and how many system packages are pending. From there, one button opens a terminal running end-4's updater and re-applies this mod afterwards.

Install

  1. Download the zip

    Use the Download button at the top of this page. It is {{ZIP_KB}} KB and contains the {{FILE_COUNT}} files plus a small install script you can read first.

  2. Unzip and run the installer

    cd ~/Downloads
unzip ii-settings-rework.zip
bash ii-settings-rework/install.sh

    It backs up every file it replaces to ~/.local/share/ii-settings-rework/backup, then copies the new ones into ~/.config/quickshell/ii. No root, no packages.

  3. Reopen Settings

    Close the settings window if it is open and launch it again. The shell itself does not need a restart.

Built against

dots-hyprland commit {{COMMIT}} ({{COMMIT_DATE}}). If your settings files differ from that version the installer stops and tells you which; --force installs anyway.

Uninstall

bash ii-settings-rework/install.sh --uninstall

Restores the backup and removes the added files.

After a dots update

Updating the dotfiles replaces these files with stock ones. The Update dotfiles button in About re-applies the rework for you; after a manual update, run the installer again.

Optional add-on

Per-display backgrounds

A different wallpaper, clock and weather on each monitor: the Background page gains a row per display and a choice of which display the widget settings apply to. Download it from the Sidegrade site and install it on top of this mod.

Why it is separate

The mod only replaces the settings app. The add-on also swaps 13 files of the shell's desktop background for patched copies, so a dotfiles update that touches them keeps the add-on off until it is rebuilt. The mod keeps working either way.
